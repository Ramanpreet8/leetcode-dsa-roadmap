## Introduction

Welcome to my personal Data Structures and Algorithms (DSA) learning journey using **Python 3**.
This repository is systematically organized to balance rigorous conceptual theory with hands-on interview preparation.
Theoretical concepts are studied directly through curated **GeeksforGeeks** articles, and problem-solving techniques are honed using hand-picked **LeetCode** problems spanning fundamental to advanced patterns.

## Learning Objectives

- **Improve Problem-Solving Skills:** Develop intuition for decomposing complex algorithmic challenges.
- **Master Fundamental & Advanced DSA:** Build solid foundations in data structures from arrays and linked lists to segment trees and tries.
- **Recognize Algorithmic Patterns:** Identify key techniques (Two Pointers, Sliding Window, Monotonic Stack, Backtracking, DP transitions, Graph traversals).
- **Analyze Time & Space Complexity:** Derive accurate Big-O asymptotic runtime and auxiliary memory bounds for every solution.
- **Write Clean & Efficient Python Code:** Follow idiomatic Python 3 standards, PEP 8 guidelines, and modular design.
- **Prepare for Technical Interviews:** Build confidence for Software Engineering technical assessments and whiteboard interviews.

## Learning Resources

- **Theory:** [GeeksforGeeks (GFG)](https://www.geeksforgeeks.org/) — Authoritative articles on data structures, algorithmic paradigms, and complexity analysis.
- **Practice:** [LeetCode](https://leetcode.com/) — Curated problems covering Easy, Medium, and Hard tiers.
- **Language:** Python 3 — Clean, idiomatic implementations.

## Daily Commitment & Learning Routine

**Daily Target:** 2 LeetCode problems per day.
**Weekly Target:** 14 problems per week.

### Suggested 90-Minute Schedule

| Time Block | Duration | Activity |
|:---|:---:|:---|
| **Phase 1** | 15 mins | Read the assigned GeeksforGeeks theory article & internalize core concepts |
| **Phase 2** | 35 mins | Attempt Problem 1 (understand edge cases, formulate approach, implement) |
| **Phase 3** | 35 mins | Attempt Problem 2 (analyze time/space complexity, implement solution) |
| **Phase 4** | 5 mins | Update [PROGRESS.md](PROGRESS.md) and [DAILY-LOG.md](DAILY-LOG.md), then commit to Git |

> [!TIP]
> **Sunday Revision:** Sundays are reserved primarily for revision, analyzing mistakes, and retrying previously difficult problems marked for review. The schedule is a guideline designed for consistent momentum, not a rigid constraint.

## Solution File Naming Convention

Every canonical Python solution follows the 4-digit problem numbering standard:

```text
<4-digit-leetcode-id>_<snake_case_problem_name>.py
```

Examples:
- `0001_two_sum.py`
- `0121_best_time_to_buy_and_sell_stock.py`
- `0217_contains_duplicate.py`
