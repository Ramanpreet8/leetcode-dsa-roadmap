# Python Problem Solution Template

Every Python solution file in this repository follows this standardized template structure:
```python
"""
Problem: [Problem Name]
LeetCode: [Official URL]
Difficulty: [Easy/Medium/Hard]
Topic: [Topic]
Pattern: [Pattern]

Time Complexity: [Your analysis]
Space Complexity: [Your analysis]

Approach:
Write your own explanation after solving.
"""

class Solution:
    pass
```

### Key Template Guidelines
1. **Do not modify the file header format:** Keep the docstring metadata uniform across all folders.
2. **Document complexity analysis:** Always include explicit Big-O time and auxiliary space complexity analysis.
3. **Write concise approach explanations:** Summarize key insights, invariants, and edge cases in the `Approach:` section.
4. **Use clean, idiomatic Python 3:** Include type hints and adhere to PEP 8 standards.
