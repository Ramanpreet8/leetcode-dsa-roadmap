# Contributing & Workflow Guidelines

This repository is maintained as a personal Data Structures and Algorithms portfolio and learning tracker.

## Commit Message Standards

Follow semantic commit message formatting:

- `feat(01-arrays): solve #0001 two sum in O(n)`
- `docs(progress): update week 1 milestone progress`
- `refactor(04-two-pointers): optimize space complexity for #0042`

## Git Workflow

1. Keep `main` clean and stable.
2. Optional feature branches: `topic/01-arrays` or `problem/0001-two-sum`.
3. Update `PROGRESS.md` and `DAILY-LOG.md` after each solving session.
